# Publimax · sitio web

Landing page de Publimax (anuncios, letras 3D y fachadas en Tampico, desde 1994).

- `index.html`: página completa (HTML, CSS y JS sin dependencias, salvo Google Fonts).
- `assets/img/`: fotos de trabajos optimizadas en WebP (`-sm` = versión de 720 px) y logotipo.
- `assets/video-acabado-dorado.mp4`: video corto usado en la sección de proceso.
- `docs/`: cuestionario para el cliente y su generador.

Para verla localmente basta con abrir `index.html` en el navegador.
